Layout Editor v2
Design & execution plan · interactive

Layout Mode, rebuilt as a semantic editor.

Stop placing boxes at x/y. Compose a tree of frames with stacking & alignment — it renders like Figma, and serializes to XML the agent can turn into real code. Everything below is live: try the editor, read the plan, validate the flow.

01

The shift

The old Layout Mode stored absolute coordinates — useless to an agent. v2 stores intent: what stacks, how it aligns, what each component is and is for.

Before — coordinates
// a flat list of boxes
{ type:"button", x:120, y:340, w:140, h:40 }
{ type:"card",   x:80,  y:420, w:280, h:240 }

Agent guess: “…a button somewhere near a card?”

→
After — semantic tree → XML
<row justify="between" align="center">
  <component name="Logo" src="@ui"/>
  <component name="Button" src="@ui">
    <prop name="intent" value="primary"/>
    <note>submits signup</note>
  </component>
</row>

Agent: emits <header class="flex justify-between…"> + the real components.

02

The document model

Two node kinds. Position is never x/y — it’s which frame you’re in + align / justify. Size is hug · fill · fixed (Figma’s model → flexbox).

container — a frame / group

layout stack·grid·free · direction row·col · gap · padding · align (cross) · justify (main) · width/height hug·fill·fixed · children[].

A group is just a frame. Group = wrap selection in a new frame; ungroup = splice back. Nesting is free.

component — a registry instance

componentKey · src (import path → agent) · variantValues · note (per-instance prompt) · alignSelf (left/center/right) · width/height.

Renders its real self on canvas (via the registry) — what you see is the layout.

✓ Shipped & verified: model.ts (tree + group/ungroup/move) · xml.ts (the serializer above) · defaults.ts. The sandbox below runs this exact logic.

04
Interactions

      
Simple & Figma-familiar. Alignment buttons replace dragging to coordinates; x/y is only a last-resort “free” frame.

    

      
Compose
Drag from Components, or select → click-place into a frame. Multi-select (shift / marquee).

      
Group / ungroup
⌘G wraps selection in an auto-layout frame; ⌘⇧G splices it back. The Layers tree is the backbone.

      
Align, don’t position
Left / center / right + top / middle / bottom set align·justify·alignSelf — semantic, not pixels.

      
Reparent
Drag in the Layers tree (precise) or on canvas into a frame. Cycle-guarded.

      
Resize = hug · fill · fixed
Handles only on fluid axes; intrinsic components (DatePicker) stay locked to their real size.

      
History
⌘Z / ⌘⇧Z over immutable tree snapshots. Rename · hide · lock · duplicate ⌘D.
